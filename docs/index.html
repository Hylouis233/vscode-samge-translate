核心功能

功能齐全的翻译助手，满足你的一切翻译需求

英文翻译成中文

一键将选中的英文文本翻译成中文，支持多种展示方式，让代码阅读更加轻松。

自动替换功能

翻译后自动替换原文本，支持英译中、中译英的自动替换，提高工作效率。

中文转变量名

支持将中文自动转换为多种编程命名格式，包括驼峰命名、下划线命名等10种格式。

多引擎支持

集成百度、阿里、腾讯、火山、有道、DeepL 六大翻译引擎，确保翻译准确性和稳定性。

多种展示方式

翻译结果可显示在选中文本后、OUTPUT面板、右下角提示框或鼠标悬停展示，任你选择。

灵活配置

支持自定义快捷键、翻译引擎、显示方式等，完全按照你的工作习惯来配置。

工作流程

简单三步，即可开启高效的翻译体验

1

安装插件

在 VSCode 扩展市场搜索 "VSCode Samge Translate" 并安装

2

配置引擎

选择翻译引擎并配置 API 密钥，支持多个引擎自动缓存

3

开始翻译

选中文本，使用快捷键或命令面板开始翻译

快捷键一览

英译中 Alt + X
英译中并替换 Ctrl + Shift + Alt + X
中译英 Alt + Z
中译英并替换 Ctrl + Shift + Alt + Z
中文转变量名 Shift + Alt + W

如何自定义快捷键和配置？

您可以通过以下步骤来编辑快捷键和配置项：

编辑快捷键：在 VSCode 中，通过 文件 > 首选项 > 键盘快捷方式 来设置您的快捷键（可搜索关键词"samge"快速定位相关配置项）。

编辑配置：在 VSCode 中，通过 文件 > 首选项 > 设置 > 扩展 > Vscode Samge Translate Configuration 来设置您的配置项（可搜索关键词"samge"快速定位相关配置项）。
